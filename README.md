ATM Simulation System in C

Description 

A menu-driven ATM simulation program developed in C. The program performs card validation, password authentication, balance checking, credit and debit transactions.

*** Features ***
Card number validation
Password verification
Maximum 3 password attempts
Check account balance
Credit amount
Debit amount
Insufficient balance checking
Menu-driven ATM interface

*** C Concepts Used ***
Variables and data types
if-else
while loop
do-while loop
switch-case
scanf() and printf()
Arithmetic operators
Conditional statements
Menu-driven programming

*** Technologies ***
C Programming
GCC / VS Code

*** How to Run ***
-> Compile the program:
gcc atm.c -o atm
-> Run the program:
./atm
